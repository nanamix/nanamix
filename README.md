## About Me

안녕하세요, **nanamix**입니다.  
저는 **안정적이고 효율적인 시스템을 만들고 운영하는 것**에 가치를 두는 DevOps / SRE 엔지니어입니다.

반복적인 작업은 자동화하고,  
시스템은 더 안정적으로 운영할 수 있도록 개선하며,  
문제가 발생했을 때는 빠른 복구뿐 아니라 **근본 원인을 파악하고 재발을 방지하는 것**을 중요하게 생각합니다.

인프라, 배포, 모니터링, 운영 효율화에 관심이 많으며,  
개발과 운영의 간극을 줄이는 방향으로 지속적인 개선을 추구합니다.

> Hi, I'm **nanamix** — a DevOps / SRE-focused engineer passionate about automation, reliability, observability, and building systems that scale with confidence.
